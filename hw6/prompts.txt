REPLAY PROMPT 1 — BUILD

authentication-log analyzer. Read UTF-8 JSON Lines with exactly timestamp, ip,
user, result. Require timezone-aware timestamps, valid IPv4/IPv6, printable
usernames of length 1..64, and success/failure results. Sort chronologically.
Detect 5 failures from one IP within an inclusive 300-second sliding window;
emit one repeated-failures alert per IP. Flag a success only when at least
5 preceding failures in that window match both IP and user; clear that user's
failure sequence after success. Support --threshold (2..1000), --window
(1..86400 seconds), and --output. Produce an ASCII-escaped JSON report on
stdout, and optionally create a new output file exclusively without overwriting.
Fail closed with exit code 2 on invalid input, without echoing raw input or paths.
Bound input to 2 MiB, 10000 events, and 4096 bytes per line using bounded reads.
Never execute log content, contact networks, or modify input. Include synthetic
samples/auth.jsonl with five failures then success and a normal IPv6 login;
include samples/invalid.jsonl demonstrating rejection. State heuristic limits.
